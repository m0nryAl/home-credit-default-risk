# Прогнозирование кредитного дефолта

## О проекте

Проект по прогнозированию вероятности дефолта клиента на основе данных о заявках на кредит из датасета Home Credit Default Risk.

Цель — построить модель машинного обучения для оценки кредитного риска и развернуть её в виде REST API.

## Используемые технологии

- Python
- Pandas, NumPy
- Scikit-learn
- LightGBM
- Optuna
- SHAP
- FastAPI
- Docker
- Joblib

## Этапы работы

1. Исследовательский анализ данных (EDA).
2. Предобработка признаков и обработка пропущенных значений.
3. Разделение данных на обучающую, валидационную и тестовую выборки.
4. Обучение базовой модели Logistic Regression.
5. Обучение и сравнение CatBoost и LightGBM.
6. Оценка влияния дисбаланса классов.
7. Подбор гиперпараметров LightGBM с помощью Optuna.
8. Финальная оценка модели на тестовой выборке.
9. Сохранение модели и препроцессора.
10. Разработка API на FastAPI.
11. Упаковка приложения в Docker-контейнер.

## Результаты модели

Метрики оптимизированной модели LightGBM на тестовой выборке:

| Метрика | Значение |
|---|---:|
| ROC-AUC | 0.7613 |
| Average Precision (PR-AUC) | 0.2519 |
| Precision при пороге 0.5 | 0.6270 |
| Recall при пороге 0.5 | 0.0234 |
| F1-score при пороге 0.5 | 0.0450 |

При стандартном пороге классификации 0.5 модель показывает высокую точность положительных предсказаний, но низкую полноту. Для практического применения порог следует выбирать с учётом бизнес-задачи и стоимости ошибок.

## API

Для получения предсказаний реализован REST API на FastAPI.

**Эндпоинт:** `POST /predict`

На вход передаются признаки клиента, на выходе возвращается предсказанная вероятность дефолта.

Пример ответа:

```json id="c24u8p"
{
  "default_probability": 0.4806
}
```

Интерактивная документация API доступна по адресу `/docs`.

## Запуск без Docker

Установить зависимости:

```bash id="a0u8tk"
pip install -r requirements.txt
```

Запустить API:

```bash id="l1j7se"
python -m uvicorn app:app --reload
```

Открыть в браузере: `http://127.0.0.1:8000/docs`.

## Запуск через Docker

Собрать образ:

```bash id="9ovp1u"
docker build -t home-credit-api .
```

Запустить контейнер:

```bash id="cz7f8s"
docker run -d -p 8000:8000 --name home-credit-container home-credit-api
```

Открыть документацию: `http://127.0.0.1:8000/docs`.

Остановить контейнер:

```bash id="7dsw6h"
docker stop home-credit-container
```

## Примечания

- Исходный датасет не включён в репозиторий.
- Для работы API необходимы сохранённая модель и препроцессор.
- API принимает объект `features`, содержащий все 120 исходных признаков клиента.
- Результат модели — оценка вероятности дефолта, а не окончательное решение о выдаче кредита.
